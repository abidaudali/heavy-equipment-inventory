Integrasi & Sinkronisasi Google Sheets

Hubungkan website ini langsung dengan Google Sheets agar Anda dan tim dapat mengedit data di spreadsheet kapan saja, dan data di website akan selalu terupdate secara otomatis (2-way continuous editing).

1

Buat Google Sheet & Buka Apps Script

Buka Google Sheets Baru → Klik menu Ekstensi (Extensions) → Apps Script.

2

Salin Kode Google Apps Script (Code.gs)

Paste seluruh kode di bawah ini ke editor Apps Script, lalu klik Simpan (Save):

// Kode Google Apps Script siap pakai ada di file Code.gs pada folder project ini.
3

Deploy sebagai Web App & Salin URL

Di Apps Script, klik Deploy (Terapkan) → New Deployment (Penerapan baru) → Web app.
Pilih: Execute as: Me dan Who has access: Anyone (Siapa saja).
Salin Web App URL yang dihasilkan lalu tempelkan pada kolom di bawah ini.
